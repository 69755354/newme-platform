## 自我优化要点

1. **测试工具 ≠ 用户环境**：Headless Chrome 的 React 事件问题是工具局限，不是代码 bug。以后遇到"按钮不响应"，先 API 验证再下结论。

2. **RLS 建表清单化**：每建一个表，立即建完整的 RLS（SELECT/INSERT/UPDATE/DELETE 四条），不要只建 SELECT。日志表尤其容易遗漏 INSERT。

3. **Context compaction 恢复策略**：被压缩后，第一件事读 `.hermes-tasks-*.md` 恢复状态，不凭记忆继续。

4. **团队活动追踪 = 最小化原则**：用户要的是数据，不是新系统。先修数据质量，再聚合展示。不需要新表/追踪器/定时任务。

5. **多里程碑开发必须持久化进度**：不是所有 context 都能撑到任务结束。每完成一个 milestone 就写文件，不要等最后一起写。
