# NewMe CRM v3.1 — Development Plan

**Status:** Phase 0 进行中
**Last Updated:** 2026-06-25

---

## Architecture Decisions

| Decision | Rationale |
|----------|-----------|
| milestone 独立表（非 enum stage） | 可扩展、可审计 |
| follow_up_logs（历史）+ tasks（未来） | 责任分离 |
| user_features 表（用户级 feature flag） | 灰度发布 |
| FK → profiles.id（非 auth.users） | 业务归属清晰 |
| import_batch_id（轻量 JSONB） | 60行不需要完整 import system |

## LLM Division

| Role | Model | Scope |
|------|-------|-------|
| Controller | DS v4-pro | 调度、Go/No-Go、Flight Recorder |
| Executor | GLM 5.2 (CC) | 代码扫描、小批量修改(3-5 files)、tsc/build |
| Auditor | Codex CLI | 审计、安全、scope creep |

## Key Constraints

- 不碰 auth 触发器
- 不碰 RLS 策略
- 不碰 proxy 认证逻辑
- 不改 UI 设计
- 不新增 Analytics 组件

## Migration Strategy

- 所有 schema 变更 → Supabase Management API
- 生产 migration 必须 dry-run + confirm
- 先改 ARCH_RULES 再写 migration SQL
